# 介面美術指導（Logo／圖示／按鈕／卡框）

角色、場地用 AI 生圖沒問題，但**文字和小圖示不要再用生圖**。生圖在這兩類有固定的「AI 味」：

- 中文字筆畫會變形（例如「彈」的弓部），每張圖字型都不一樣。
- 小圖示被塞滿花、貝殼、金邊、寫實光影，縮到 44px 就糊成一團，而且每顆圖示的外框粗細、光源都不同。

這些素材改成**用程式繪製**（`tools/ui-art/gen.py`），規則如下。

## 依據
- 圖示最重要的是剪影，比顏色還重要；整套的外框粗細、尺寸、圓角要一致（BPXL Craft〈10 Essential Tips for UI Icons〉）。
- 遊戲內圖示要「整套設計，不是一顆一顆設計」，用外框顏色＋形狀區分類別，顏色要有形狀撐著（Made Good Designs〈Game Icon Design〉）。
- 輕鬆向遊戲的標題字：圓體、柔軟、有彈跳感的基線、暖色（Made Good Designs〈Game Logo Design〉）。
- AI 美術的「slop 感」來自沒有美術規範：要先定規則、測可讀性、限制風格漂移，每張放回遊戲裡看（Seele AI〈How to Avoid AI Slop in Game Art〉；Adobe〈Creative direction: the secret to great AI images〉）。

## 規則
| 項目 | 規定 |
|---|---|
| 外框 | 深暖棕 `#4E2A2E`（取自角色外框），128px 圖示 7px、大元件 8～10px |
| 明暗 | 平塗＋底部一塊暗色＋左上一道高光，不用漸層光影 |
| 立體感 | 往下 4～12px 的外框色厚度（像角色的底部陰影） |
| 色票 | 珊瑚 `#F0765A`、地中海藍 `#2F86C6`、薄荷 `#57C2A0`、金 `#F2B93B`、紫 `#7B4A8E`、奶油 `#FFF3DC` |
| 圖示 | 一顆只放一個主體；白色剪影＋外框；44px 要能辨識 |
| 節點 | 戰鬥＝珊瑚雙劍、遭遇＝薄荷問號、獎勵＝金寶箱、補給＝藍泳圈、首領＝紫骷髏＋四角尖刺（剪影不同） |
| 字型 | jf open 粉圓（圓體，SIL OFL），不用生圖寫字 |
| 質感 | 最後疊一層 4～6% 的紙紋，讓向量圖和水粉角色放在一起不突兀 |
| 不要 | 碎花、貝殼、金色捲紋、寫實反光、每顆不同的光源 |
