# 方向 A：地中海度假泳池美術規範

## 視覺基調

- 手繪水粉／不透明水彩，保留紙張顆粒與柔和筆觸；輪廓採深海藍灰，不使用純黑硬邊或寫實 3D 光澤。
- 地中海度假氣氛：橘白條紋、柑橘、拱廊、海景、馬賽克磁磚、霧面金色飾邊。角色裝飾以一種主題為主，避免把所有元素堆在同一張圖。
- 共用色票（建議）：珊瑚橘 `#EF795B`、奶油白 `#FFF1D6`、地中海藍 `#367BAA`、薄荷綠 `#72C7B2`、金 `#E9B64D`、深海藍灰 `#343B50`。角色可按能力使用輔助色；不只靠顏色區分。
- 光源統一在左上，亮部大而柔和，右下有薄而清楚的暗部；不畫地面投影。使用大色塊與粗輪廓，避免細碎圖案。

## 角色構圖

- 全部是有表情的可愛球體，而非真人、寫實人形或官方 IP。球體直徑目標約畫布 80%，中心接近 (256,256)；附件可超出主體，但不接觸畫布邊界。
- 正面或輕微四分之三視角，簡化眼口，能力由單一主要剪影／飾品呈現。以整體輪廓辨識，不依賴文字或小徽章。
- 44 px 實戰顯示、64 px 縮小檢查時均應能辨識主要配件。主輪廓線在原尺寸建議約 12–20 px；縮小後不應消失。不同角色避免相似的大配件、主色及剪影同時重複。

## 驗收清單

1. 角色檔名、順序、尺寸及 alpha 通道正確；外框有透明留白，不切斷配件。
2. 用 64×64 接觸表檢查每隻角色，再以 44×44 實戰大小確認剪影和大配件。
3. 在淺奶油與深海藍兩種底色檢查輪廓、透明邊緣及辨識度。
4. 同批配色、筆觸與視角一致，不混入官方 IP；後續批次以同一規範延續。
5. 僅新增美術素材和文件，不修改遊戲程式或既有檔案。
