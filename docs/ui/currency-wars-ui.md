# 介面參考：《崩壞：星穹鐵道》貨幣戰爭 → 彈射自走棋（橫向手機版）

v1.2 起遊戲改為**只支援橫向**（manifest `orientation: landscape`，直拿會蓋一層「請轉成橫向」）。
這份文件整理貨幣戰爭的版面與操作邏輯，以及我們怎麼套用。只學版面與操作，不用它的美術素材與角色。

## 1. 研究重點（貨幣戰爭）

| 項目 | 貨幣戰爭的做法 | 來源 |
|---|---|---|
| 經驗等級 | 畫面**左下**；用金幣買經驗升級，等級決定可上場人數，也提高高費角色出現率 | Prydwen、bilibili wiki |
| 隊伍區 | 上場區（前台，最多 4）＋場下區（後台，最多 6，自動支援、不會被打） | Prydwen、Enjoygm |

| 商店 | **右下**「商店」打開；每個節點自動刷新 1 次，可花金幣手動刷新，可**鎖定**（不自動刷新）；1～5 費，顏色白／綠／藍／紫／金 | Prydwen、bilibili wiki、Enjoygm |
| 賣角色 | 按住角色拿起來，**左下、右下**同時出現「出售」區，拖過去就賣 | Prydwen |

## 2. 資訊層級（我們的取捨）

1. **一眼要看到**：小隊血量、金幣（＋下一場利息）、等級／經驗、位面節點走到哪 → 上方資訊列。
2. **佈陣時常看**：前台／後台格子與可上場數（`前台 2/3`）、啟動中的羈絆與「差幾隻」→ 中央＋左側。
3. **買東西時看**：卡片費用（左上色塊）、站位、羈絆、能不能升星（金色「再 1 隻升星」）、買不起（費用變灰）、備戰區已滿（打叉）→ 商店卡。
4. **需要時才看**：角色詳細、裝備詞條、環境／策略說明 → 點一下顯示在右側詳情欄；長按商店卡開完整說明。

### 操作

| 動作 | 結果 |
|---|---|
| 點商店卡 | 購買（進備戰區；湊滿 3 隻自動升星）|
| 拖商店卡到格子 | 購買並直接放到那格 |
| 長按商店卡 | 完整說明（可在彈窗內購買）|
| 點角色 | 選取；右側顯示詳情＋「出售」「詳細」；再點空格移動、點別隻交換 |
| 長按角色 0.3 秒或直接拖 | 拿起來；拖到格子交換位置；拖到左下／右下「出售」區賣掉 |
| 點／拖裝備或武器（右上） | 點＝看詞條；拖到角色身上＝裝備（拖曳中只有有角色的格子會亮）|
| 點／拖道具（虛線框，例：扳手） | 扳手拖到角色＝拆回所有裝備；冶金爐等照原本規則 |
| 點羈絆／策略／環境 | 右側詳情顯示各階效果 |
| 左側「羈絆 ◀」 | 收合成只剩圖示＋數量（記在設定 trFold）|
| ☰ | 匯出隊伍代碼、代碼對戰、設定 |

拖曳門檻 8px；長按 0.3 秒拿起來（舊版是 0.45 秒開詳細彈窗）。拖曳時商店抽屜自動變透明，下面的格子都能放。

### 單手、慣用手
- 重要按鈕全在最下排（拇指區）：左下升級、正中刷新／鎖定、右下商店／出發。
- 設定「左手」時：按鈕列左右對調（出發在左下）、羈絆欄與情報欄左右對調、戰鬥大招鈕移到左下。

## 5. 結算

橫向兩欄：左＝勝敗大字、原因、小隊血量變化、金幣明細；右＝動數與戰鬥數據格、戰利品。底部一顆大「繼續 ▶」。

## 6. 戰鬥場地（橫向）

**方案：左右對戰（我方在左、敵方在右）**，不改物理。

- `src/core` 的世界座標仍是直式（`arena 560×840`，我方在下）。`src/ui/render.js` 在橫向時（`innerWidth > innerHeight`）把整個場地層 **旋轉 90°**：`螢幕 x = W − (CY + y·S)`、`螢幕 y = CX + x·S`。
- 棋子、血條、名字、傷害數字、力道條、柱子都在自己的中心點「反轉回正」，所以字不會躺著；速度拉伸、碰撞壓扁的角度同步 +90°。
- 輸入：`V.toWorld()` 做反向換算，`V.toScreen()`／`V.scale()` 給教學泡泡、手指示範、測試用。拉射的角度與力道都在世界座標算，所以 AI、預演線、隊伍代碼對戰、重播結果完全不變。
- 連線 1v1／連線自走棋的客人端原本就把資料翻 180°（自己永遠是 team0、在下方）；旋轉只發生在畫面層，所以客人端也是「自己在左」，出手角度補 π 的邏輯不用改。
- 為什麼選左右而不是「直式場地放中間」：直式場地放在 390 高的畫面，縮放比只有 0.44，棋子直徑 16～26px，太小不好拉；轉 90° 後縮放比 0.65（和舊直式一樣），兩側還有 ~120～150px 放資訊。
- HUD：左欄＝回合資訊與動數條（`.bhud`）、短按棋子的資訊卡；右欄＝1x/2x、暫停、⚡大招（拇指位置）。場地左右邊界以 CSS 變數 `--arena-l`／`--arena-r` 提供給版面。

## 7. 美術替換（地中海度假泳池）

先用 CSS 做配色：地中海藍面板（`#0f4c75`→`#0b3a5c`）、奶油白按鈕（`#fff6e6`/`#f3e2c2`）、珊瑚橘主按鈕（`#ff9a76`→`#d24a24`）、薄荷綠（後台格、經驗條）、金（升星、鎖定、金幣）。格子：前台＝泳池藍磁磚、後台＝薄荷綠、備戰＝沙色。

面板、按鈕、卡框都預留 9-slice：在 `:root` 設定圖片就會套用（切 24px、內容 fill）：

```css
:root{
  --img-panel:url(assets/art/ui/panel.png);   /* .ui-panel、彈窗 .box */
  --img-btn:url(assets/art/ui/btn.png);       /* 一般按鈕 */
  --img-go:url(assets/art/ui/btn-go.png);     /* 出發等主要按鈕 */
  --img-card:url(assets/art/ui/card.png);     /* 商店卡框（費用色仍由 --cc 控制） */
}
```

新增圖片檔時記得加進 `sw.js` 的快取清單。

## 8. 已知限制
- 裝備疊裝備合成（貨幣戰爭的拖一件到另一件上）需要核心規則支援，本次沒做（`src/core` 由另一位負責）；目前仍是裝到同一隻角色身上時自動合成。
- 商店抽屜打開時會蓋住備戰區，抽屜標題列顯示「備戰空位 n」；要整理備戰區時按「商店 ▾」收起，或開始拖曳時抽屜會自動變透明。
- 教學泡泡文字（main.js 的 TUT）仍寫「前進」「底部出現賣出區」，由負責教學文字的人同步。
